# Искра
Творческая мастерская: идеи, палитры, холст, таймер и заметки. Логотип — векторная трассировка рисунка пользователя.

## Публикация
В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root), затем Save. После успешного развёртывания адрес: https://chunhun90-a11y.github.io/iskra/

## Данные
Приложение не отправляет заметки и рисунки на сервер. Избранное и заметки хранятся в localStorage; рисунок нужно скачивать вручную. GitHub Pages получает обычные запросы посетителей. Это не гарантия полной анонимности.

Без внешних зависимостей. В Safari сборка не проверена.
